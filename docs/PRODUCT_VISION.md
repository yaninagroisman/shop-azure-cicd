# Product Vision

## Positioning

**Immersive & Gamified E-commerce Platform.** *Turn shopping into an adventure.*

It is a platform for atmospheric, interactive online stores. Each store gets a distinctive visual setting, hidden mini-games, achievements, rewards and secret products, and the whole thing can be rebranded.

## Origin

The project started as a practical Full-Stack and DevOps project after the owner's training at Infinity Labs R&D. The course required:

- a Flask client;
- a backend API;
- MongoDB;
- Kafka, with synchronous reads and asynchronous writes.

The long-term goal is a stand-alone commercial product.

## Business model

**Exclusive Source Code Sale**: the source code is sold once to one buyer, with the transferable intellectual-property rights. It is not SaaS, not a subscription, and there is no long-term support obligation.

The price hypothesis is **$3,000–6,000**. It is **unconfirmed** and gets tested in Phase 3.

## Target buyers

- Toy shops.
- Collectibles shops.
- Artisan confectioners and unusual desserts.
- Original gift shops.
- Themed shops.
- Digital agencies and web development studios, which can resell it as a bespoke store.

## What makes it different

1. **A cinematic, photographic shop window** instead of a template grid:
   - an animated storefront with a clickable door and sign;
   - products staged on a lit display niche.
2. **Every product "does something"**: hop, fizz, spark, smoke, open.
3. **Play is built into shopping:**
   - a mini-game behind the shop door;
   - typed secret words;
   - a hidden chart;
   - a family clock that reacts while an order is in flight.
4. **A fantasy currency**, configurable later, with a standard-currency mode.
5. **A lean stack a buyer can own:** Flask, Jinja2, vanilla JS and CSS. There is no frontend framework and no build step.

## Guiding principles

- Keep the unique visual concept. Universality must not flatten it.
- Game mechanics must be independent of the store's theme.
- Add complexity only where it brings commercial value.
- Demo payments are always clearly labelled. Real payments come after v1.
- Everything a buyer receives must be free of third-party IP and documented well enough to run without the author.

## Current demo theme

**Marvellous Mischief Co.**, a Victorian joke shop at No. 7 Crooked Lane run by the twins Rufus & Reynard. It has 13 products on 4 shelves, and prices are in Griffins, Shards and Pips.
